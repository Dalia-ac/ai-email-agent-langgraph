#  AI Email Agent with LangChain & LangGraph

A stateful AI email agent built with **LangChain**, **LangGraph**, and **Google Gemini**.

This project explores how to build an AI agent that can use tools, maintain state, dynamically control tool availability, authenticate users, and require human approval before performing sensitive actions.

> **LLM + Tools + State + Middleware + Human-in-the-Loop**
